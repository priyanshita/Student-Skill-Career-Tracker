# Academic Problem Statement & Objectives

## Project Title: Student Skill & Career Tracker

### 1. Problem Statement
College engineering students (specifically in CSE and AI-ML disciplines) often struggle to align their ongoing academic learning, self-study skills, personal projects, and certifications with real-world industry career roles (e.g., AI/ML Engineer, Software Developer, Data Scientist, Cloud Engineer). 

Existing solutions are often generic web spreadsheets or complex enterprise tools that lack personalized skill-gap identification and algorithmic career readiness evaluation. There is a need for a modular, offline-first desktop application that allows students to systematically record technical/soft skills, quantify their proficiency, map their progress against target career roles, and compute an objective career readiness score based on a transparent mathematical formula.

### 2. Objectives
- **Skill Profile Tracking**: Provide a centralized interface for students to log, categorize, and update technical and soft skills with beginner/intermediate/advanced proficiency.
- **Portfolio Management**: Record project achievements and industry certifications linked to specific technical competencies.
- **Algorithmic Skill Gap Analysis**: Dynamically compare acquired skills against benchmark requirements of target career roles to classify skills into *Acquired*, *Partially Developed*, and *Missing*.
- **Career Readiness Score Computation**: Implement a multi-component weighted formula to calculate an objective career readiness score ($0 - 100\%$).
- **Object-Oriented Demonstration**: Fulfill 2nd-year academic computer science requirements by demonstrating core Java OOP concepts (Classes, Abstract Base Classes, Subclassing, Interfaces, Encapsulation, Polymorphism, Method Overriding, Method Overloading, Custom Exceptions, File Handling, and Data Structures).

### 3. Target Audience & Scope
- **Target Audience**: 2nd Year B.Tech Computer Science & Engineering (CSE) / Artificial Intelligence & Machine Learning (AI-ML) students.
- **Scope**: JavaFX-based desktop GUI application with text file data persistence (`.txt`), sorting/searching algorithms, and unit testing suite.
